## Pitch draft

Skin Casefile turns a worrying skin change into a clear record you can take to a qualified professional. It combines YouCam Skin Analysis readings with the dates and product context you enter, then shows what changed without pretending correlation is diagnosis. The project uses the official asynchronous YouCam API and stores the record only in the user's browser. The image is sent to YouCam, where API policy says uploaded data is generally retained for 30 days after a completed session; each successful four-concern scan uses 9 API units under the published schedule.

## Submission description draft

Skin Casefile helps a person record a skin change before trying another product or routine. Start a case in your own words, add the product or routine context you remember, and submit a front-facing photo with consent. The app sends it through Perfect Corp's File API to YouCam Skin Analysis v2.1, then keeps the returned acne, redness, moisture, and oiliness readings with a timestamp. Add a later scan to see the provider's values side by side and note what changed. Skin Casefile does not diagnose, prescribe a routine, or claim that a score movement proves a product caused it. It keeps notes and returned readings in local browser storage and provides a print view that can help organize a conversation with a qualified professional. The selfie is sent to YouCam; its API privacy policy says uploaded data is generally retained for 30 days after a completed session. A successful four-concern SD scan uses 9 API units under the published schedule.
