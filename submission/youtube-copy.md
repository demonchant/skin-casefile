## Title

Skin Casefile — Keep the Context With the Change

## Description

Skin concerns can be hard to track over time. Skin Casefile brings personal notes, routine context, dated check-ins, and real YouCam Skin Analysis readings into one private case timeline.

This demo shows the concern-record flow, consented photo analysis through YouCam's File API and Skin Analysis API, returned measurements, follow-up comparison, and a print-ready summary. Skin Casefile helps people keep a clearer record; it does not diagnose skin conditions or explain what caused a change.

Project repository: https://github.com/demonchant/skin-casefile

Try the live app: https://skin-casefile.onrender.com/
